## About

Full-stack software engineer specializing in scalable web platforms built with Next.js, React, TypeScript, and Node.js on PostgreSQL. I shipped and ran a production platform serving a **25,000+ member community** (500+ DAU) as Director & CTO, with hands-on depth in distributed systems, real-time infrastructure (WebRTC, Socket.IO, Redis), and cloud-native deployment on AWS.

- Software Engineer at **Deal Bana**, building a multi-vendor e-commerce marketplace on Next.js 15 and PostgreSQL
- Open source contributor and former **Tools Manager at Wikimedia Foundation** (Toolforge)
- Junior Researcher in **Cryptography & Network Security at MNNIT Allahabad**
- Founder of **WikiClub SHUATS** and Co-Organizer at **GDG Prayagraj**
- B.Tech in Computer Science & Engineering, SHUATS '26
